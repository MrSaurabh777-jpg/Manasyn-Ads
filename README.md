# Manasyn-Ads

Marketing & organic-content workspace for **Manasyn** — manasyn.app · *Your intelligent companion for mental healthcare.*

| Path | What it is |
|---|---|
| `MANASYN-DETAILS.md` | **Single source of truth** — verified brand & product facts, palette, logo rules, compliance rules, citable numbers. Read first. |
| `MAYA-AGENT-PROMPT.md` | The MAYA social-media content agent brief (v2.0) + reconciliation patch. |
| `maya-content/` | Daily 3-post content packages produced by MAYA (Week 1 · Day 1 done). **`week-01/day-01/final/` is ready to post** — finished images, captions, alt text and a timed run-sheet. See `maya-content/README.md`. |
| `scripts/maya_render/` | Renderer that bakes text/logo/badge/watermark into the base images and builds the caption pack + run-sheet. |
| `brand/` | Logo files: full lockup, transparent lockup, white-card lockup, square emblem, transparent emblem. `brand/fonts/` = Poppins + Inter (OFL) used by the renderer. |
| `1001042846.png` | Original logo upload (kept untouched). |
| `scripts/composio/`, `.github/workflows/` | Composio bridge for automated LinkedIn posting (earlier work). |

Other branches hold earlier series (e.g. `linkedin-week/` on `arena/01a0a103-manasyn-ads`).
